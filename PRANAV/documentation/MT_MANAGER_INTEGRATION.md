# MT Manager Authorized APK Integration Guide

> **Authorization & Policy Boundary**: Only integrate PRANAV into APKs that you own or have explicit legal authorization to maintain and distribute. Never use these workflows to strip DRM, bypass license checks, or defeat anti-tamper controls.

## Step-by-Step MT Manager Workflow
1. **Run Inspection First**: Open your authorized APK in **PRANAV Admin -> DEX & Hook -> APK Assistant** or run:
   ```bash
   node PRANAV/integration/apk-assistant/pranav_apk_inspector.js target.apk
   ```
   Note the `dexFiles` count (e.g., `classes.dex` -> next slot is `classes2.dex`), `applicationClass`, and `recommendedHook`.
2. **Backup the Original APK**: Keep a clean copy before any edit for instant rollback.
3. **Add `pranav-sdk-1.4.0.dex`**:
   - Open the APK archive in MT Manager (`View`).
   - Rename `pranav-sdk-1.4.0.dex` to the next sequential DEX name (`classes2.dex` or `classesN+1.dex`) and add it to the root of the APK archive.
4. **Compile & Insert Separate Hook**:
   - Either add the small compiled `hook.dex` (`com.pranav.integration.hook.*`) or merge `PranavApplicationHook` / `PranavActivityHook` Smali into the host class's DEX.
   - Insert the `invoke-static` snippet generated by the PRANAV APK Assistant inside `onCreate()` right after `invoke-super`.
   - Ensure `.locals` register count in the target method is sufficient for `v0` and `v1` (increase `.locals` by +2 if needed, or reuse safe unused registers).
5. **Check Permissions in `AndroidManifest.xml`**:
   - Verify `android.permission.INTERNET` and `android.permission.ACCESS_NETWORK_STATE` exist.
6. **Align & Sign**:
   - Sign with your owner keystore (v2 + v3 scheme recommended for Android 7–16).
7. **Post-Integration Validation**:
   - Run `pranav_apk_inspector.js` on the output APK to confirm `hasPranavSdk: true`, valid signature schemes, and exact entry point.
